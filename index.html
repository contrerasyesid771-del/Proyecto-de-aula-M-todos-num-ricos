Cómo se encoge el intervalo

¿Qué es el método de bisección y cómo funciona?

La idea

Queremos resolver f(x) = 0. Si f es continua en [a, b] y f(a) y f(b) tienen signos opuestos, el teorema de Bolzano (valor intermedio) garantiza que hay al menos una raíz dentro. Después se parte el intervalo por la mitad y nos quedamos con la mitad donde el signo todavía cambia.

Algoritmo

  1. Verificar que f(a)·f(b) < 0.
  2. Calcular el punto medio c = (a + b) / 2.
  3. Si f(c) = 0, c es la raíz y se termina.
  4. Si f(a)·f(c) < 0, la raíz está en [a, c] y se hace b = c; si no, está en [c, b] y se hace a = c.
  5. Desde la segunda iteración, calcular |c nuevo − c anterior| / |c nuevo| × 100. Si el punto medio actual es cero, el porcentaje queda sin definir. Detenerse cuando el porcentaje sea menor o igual que la tolerancia.

Cota absoluta y error porcentual

La cota absoluta E = (b − a)/2 se obtiene del intervalo de cada paso. El error porcentual compara dos puntos medios sucesivos, por eso la primera fila muestra un guion en esa columna.

Ventajas

  • Siempre converge si hay cambio de signo.
  • Muy simple de programar.
  • Se sabe de antemano cuántos pasos hacen falta.

Limitaciones

  • Convergencia lenta (lineal): gana 1 bit de precisión por paso.
  • Necesita un intervalo con cambio de signo.
  • No detecta raíces donde f toca el eje sin cruzarlo (ej. x²).
  • Una asíntota (ej. 1/x) puede parecer una raíz: hay que revisar f(c).
